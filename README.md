# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux Toolkit. Shoppers can browse houseplants by category, add them to a cart, and manage quantities before checkout.

## Features

- **Landing page** with a background image, the company name, an About Us section, and a "Get Started" button.
- **Product listing page** with six plants in each of five categories (Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, Low Maintenance). Each plant shows a thumbnail, name, description, and price.
- **Add to Cart** buttons that disable once a plant is added and update the cart icon count.
- **Navbar** with links to Home, Plants, and Cart on both the product and cart pages.
- **Shopping cart page** showing each plant's thumbnail, name, unit price, and subtotal, the total cart amount, buttons to increase or decrease quantity, a delete button, a Checkout button ("Coming Soon"), and a Continue Shopping button.

## Tech stack

- React 18 + Vite
- Redux Toolkit / React Redux for cart state

## Running locally

```bash
npm install
npm run dev
```
